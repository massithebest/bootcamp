# 지식 관리 구조화 상세 가독성 개선 계획

**상태: 완료 · 2026-09-16**

## 문제

- 구조화 YAML 상세의 배열·객체가 `JSON.stringify` 결과로 노출되어 대괄호,
  따옴표, `null`과 제각각인 들여쓰기가 화면의 주된 표현이 된다.
- 태그, 컬럼 정의, 업무 규칙, SQL 예시처럼 의미가 다른 목록이 동일한 raw text로
  표시되어 훑어보기 어렵다.
- 좌측 지식 목록도 유형·상태·제목·요약의 정렬과 선택 표시가 명확하지 않다.

## UI 원칙과 범위

- Backend 응답과 YAML 계약은 변경하지 않고 Frontend 표시만 개선한다.
- 최상위 상세는 `필드명 | 값` 구조로 통일하고 snake_case 키는 사용자용 라벨로
  변환한다. 식별자·SQL·숫자에는 기존 mono 규칙을 유지한다.
- 태그와 grain 계열은 줄바꿈 가능한 chip, 문장 배열은 불릿 목록, 컬럼 배열은
  이름·형식·설명의 반복 행, SQL 예시는 질문·SQL·답변 블록으로 표시한다.
- 최상위 빈 값은 `없음`으로 명시하되 컬럼 내부의 선택적 빈 필드는 반복하지 않는다.
- 좌측 목록은 유형·상태를 한 행에 맞추고 선택 항목을 accent 좌측 룰과 배경으로 표시한다.

## 완료 조건

- 구조화 상세에서 raw JSON 구문이 기본 표현으로 보이지 않는다.
- 동일 종류의 값이 같은 타이포그래피·간격·구분선으로 표시된다.
- 긴 값과 chip은 좁은 폭에서도 줄바꿈되며 페이지 가로 스크롤을 만들지 않는다.
- Frontend test/build/lint 및 실제 브라우저 화면 검증을 통과한다.

## 완료 기록

- 재귀 구조화 렌더러를 분리해 단일 값, chip, 문장 목록, 컬럼, 중첩 객체와 SQL
  예시를 의미별 UI로 표시했다.
- 좌측 지식 항목의 정보 위계와 현재 선택 표시를 정렬했다.
- Frontend 54개 테스트, production build, lint(오류 0건·기존 경고 13건),
  지식 관리 브라우저 회귀 5개, 실제 관리 화면의 raw JSON 제거·400px 가로 넘침
  없음·상세 영역 WCAG A/AA 위반 0건을 검증했다.
