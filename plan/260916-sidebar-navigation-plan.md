# ChatGPT형 좌측 전역 내비게이션 계획

**상태: 완료 (2026-09-16).**

## 목표

지식 관리 화면에서 중앙 헤더의 별도 복귀 버튼에 의존하지 않고, ChatGPT처럼
좌측 사이드바의 일관된 전역 메뉴로 채팅과 지식 관리를 오갈 수 있게 한다.

## 범위와 계약

- 좌측 상단에 `새 채팅`, `채팅`, `지식 관리` 목적지를 둔다.
- 현재 목적지를 시각적 상태와 `aria-current`로 함께 표시한다.
- `채팅`은 기존 대화의 입력·스트리밍·스크롤 상태를 보존해 복귀하고,
  `새 채팅`만 대화를 초기화한다.
- 최근 대화 목록과 비영속 안내, 사이드바 접기, 사용자 영역은 유지한다.
- 지식 편집 중 이동은 기존 미저장 변경 확인 절차를 그대로 거친다.
- Backend, `AgentEvent`, 지식 API와 세션 영속화 계약은 변경하지 않는다.

## 완료 조건

- 중앙 헤더의 `대화로 돌아가기` 버튼 없이 좌측 메뉴로 채팅에 복귀한다.
- 채팅/지식 관리의 현재 위치와 키보드 포커스가 명확하다.
- 관리 화면 왕복 시 Composer DOM·초안·스트리밍·스크롤이 보존된다.
- `npm test`, `npm run build`, `npm run lint`와 브라우저 회귀를 통과한다.

Frontend 세부 작업과 검증 기록은
