# 좌측 채팅 메뉴 단일화 계획

**상태: 완료 (2026-09-16).**

## 목표와 범위

좌측 전역 메뉴에서 같은 채팅 목적지를 가리키는 `새 채팅`과 `채팅`의 중복을
제거하고 `새 채팅` 하나로 통일한다. 지식 관리에서 현재 대화로 돌아갈 때는
현재로 표시된 최근 대화 항목을 사용하며 Composer 초안·스트리밍·스크롤을 보존한다.

새 채팅은 현재 실행 동안 `새 대화` 항목을 최근 목록에 추가해 지식 관리에서도
복귀 경로를 유지한다. Backend, AgentEvent, 지식 API와 영속 세션 계약은 변경하지 않는다.

## 완료 조건

- 좌측 주요 메뉴에는 `새 채팅`과 `지식 관리`만 표시된다.
- 현재 최근 대화로 복귀할 때 대화 상태와 미저장 지식 이동 보호가 유지된다.
- Frontend 기본 검증과 브라우저 지식 워크스페이스 회귀를 통과한다.

실행과 검증 기록은
[Frontend 계획](../frontend/plan/260916-chat-navigation-unification-plan.md)에 둔다.
