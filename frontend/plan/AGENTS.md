# Frontend 계획 지침

- `Todo.md`에는 해야 할 일과 검토 전 아이디어를 기록한다.
- `InProgress.md`에는 착수한 작업의 상태와 현재 계약을 기록한다.
- `History.md`에는 완료 결과·검증·대체된 결정을 기록한다.
- 큰 작업의 세부 실행 계획만 `<yymmdd>-<topic>-plan.md`에 기록한다.
- 계획은 Frontend만으로 이해할 수 있게 범위, 기대 API·UI 상태, 오류, 검증과 완료
  조건을 적고 준비되지 않은 Backend 값을 추측하지 않는다.
- 계약 변경은 타입·parser·fixture·UI와 함께 반영한다. 완료된 상세 계획은 핵심
  결정을 `History.md`에 합친 뒤 제거한다. 남은 일은 `Todo.md`로 돌린다.
- 실행과 검증은 `../AGENTS.md`를 따른다.
