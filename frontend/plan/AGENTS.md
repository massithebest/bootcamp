# Frontend 계획 지침

- `Todo.md`가 기대 API·다음 작업·완료 이력의 기준이다.
- 작은 작업은 `Todo.md`에, 큰 작업만 `<yymmdd>-<topic>-plan.md`에 기록한다.
- 계획은 Frontend만으로 이해할 수 있게 범위, 기대 API·UI 상태, 오류, 검증과 완료
  조건을 적고 준비되지 않은 Backend 값을 추측하지 않는다.
- 계약 변경은 타입·parser·fixture·UI와 함께 반영한다. 완료된 상세 계획은 핵심
  결정만 `Todo.md`에 합친 뒤 제거한다.
- 실행과 검증은 `../AGENTS.md`를 따른다.
