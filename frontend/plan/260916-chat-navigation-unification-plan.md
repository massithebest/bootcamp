# 좌측 채팅 메뉴 단일화 Frontend 실행 계획

**상태: 완료 (2026-09-16). 상위: [공통 계획](../../plan/260916-chat-navigation-unification-plan.md).**

## 작업

1. Sidebar의 `채팅` 항목을 제거하고 `새 채팅`과 초기화 callback만 유지한다.
2. 현재 대화를 최근 목록에 표시하고 같은 항목 선택 시 상태를 보존해 복귀한다.
3. 디자인 가이드·결정 기록과 브라우저 회귀를 현재 동작에 맞춘다.

## 검증

- `npm test`, `npm run build`, `npm run lint`
- 브라우저에서 `새 채팅` 단일화, 최근 목록 복귀와 Composer 초안 보존 확인

## 실행 기록

- `npm test` 52개, build, lint를 통과했다. lint는 기존 Fast Refresh 경고
  13개만 유지되고 오류는 없다.
- 브라우저에서 주요 메뉴가 `새 채팅`, `지식 관리`만 포함하는지 확인했다.
- 새 채팅 생성 시 `새 대화 · 방금 전` 최근 항목이 추가되고, 지식 관리에서
  해당 항목으로 복귀한 뒤 Composer 초안이 보존되는 것을 확인했다.
- 지식 워크스페이스 브라우저 회귀 5개가 모두 통과했다.
