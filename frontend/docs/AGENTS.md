# Frontend 참고 문서 지침

- 이 폴더에는 폐쇄망 반입·운영 원칙과 지속적으로 유효한 프론트엔드 기술 결정을 둔다.
- 구현 일정, Task와 진행 체크리스트는 `frontend/plan`에 둔다.
- 결정 기록은 날짜, 상태, 결정, 근거, 영향과 대체된 기존 결정을 간결하게 남긴다.
- 실행 절차나 코드 목록을 복제하지 않고 관련 상위·하위 계획으로 연결한다.
- 패키지 검증 문서에 Nexus URL, 계정이나 사내 경로를 넣지 않는다.
- 문서 이동이나 제목 변경 시 README, 계획, 코드 주석의 상대 링크를 함께 갱신한다.
