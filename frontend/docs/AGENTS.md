# Frontend 참고 문서 지침

- 이 폴더에는 폐쇄망 반입·운영과 assistant-ui 사용처럼 반복해서 쓰는 업무
  가이드를 둔다. 현재 제품별 UI 결정은 `../plan/InProgress.md`에 기록한다.
  운영자가 매번 실행할 절차와 점검 목록은 남긴다.
- 새 개발 업무·아이디어는 `../plan/Todo.md`, 착수한 업무·현재 계약은
  `../plan/InProgress.md`, 완료 결과·검증·대체된 결정은 `../plan/History.md`에 둔다.
  docs에 날짜별 개발 일지나 프로젝트 작업 체크리스트를 추가하지 않는다.
- 비밀값·사내 URL·인증 정보는 기록하지 않는다. 문서 이동 시 README·계획·코드
  주석의 링크를 함께 갱신한다.
