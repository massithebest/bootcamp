# Backend 참고 문서 지침

- 이 폴더에는 폐쇄망 반입·운영·이식과 도메인 지식 관리처럼 업무 수행 중 반복해서
  적용할 절차, 계약 설명, 예시를 둔다. 운영자가 매번 실행할 점검 목록은 남긴다.
- 새 개발 업무·아이디어는 `../plan/Todo.md`, 착수한 업무·현재 계약은
  `../plan/InProgress.md`, 완료 결과·검증 이력은 `../plan/History.md`에 둔다.
  날짜별 개발 일지나 프로젝트 작업 체크리스트를 docs에 추가하지 않는다.
- 새 문서 파일명은 대문자로 작성한다. 단어 구분은 하이픈 또는 밑줄을 쓰고,
  Markdown 확장자는 `.md`로 둔다.
- 비밀값·사내 URL·인증 정보와 반입 금지 데이터를 기록하지 않는다.
- 지식 YAML의 값을 복제하기보다 필드 의미와 작성·검토 절차를 설명한다.
- Git에 포함된 자산과 별도 반입하는 dataset·script를 구분하고, 문서 이동 시
  README·계획·코드 주석의 링크를 함께 갱신한다.
